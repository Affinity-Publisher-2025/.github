## Desktop Publishing and Page Layout

Affinity Publisher provides a workspace for arranging text, images, and graphic elements across individual pages and multi-page documents. Designers can establish consistent layouts, manage typography, and prepare publications for digital distribution or printing.

The application is suited to editorial design, marketing collateral, reports, books, and other projects that require precise control over page structure and visual hierarchy.

## Typography and Text Flow

Typography plays a central role in editorial and document design. Affinity Publisher provides controls for formatting text, adjusting spacing, and positioning content within frames.

Text frames can be linked so that content continues between designated areas or pages. This is particularly useful for long documents in which the amount of text may change during editing.

Typical applications include:

- Establishing heading and body-text styles.
- Managing paragraphs and text alignment.
- Adjusting character and line spacing.
- Connecting text across multiple frames.
- Organizing captions, footnotes, and supporting information.
- Maintaining consistent typography throughout a publication.

Careful text organization helps improve readability and reduces layout inconsistencies.
